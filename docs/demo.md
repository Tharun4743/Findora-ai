## 3. Judge-Facing Differentiators Cheat Sheet

If asked:
* *"Isn't this just keyword search?"*
  → **No**. It combines 8-signal multimodal vector cosine similarity, Haversine campus zone decay, and exponential time decay.
* *"How do you prevent fraudulent claims?"*
  → **The Blind-Match Ownership Protocol**. Claimants must answer questions derived from hidden traits without ever seeing what the finder logged.
* *"What if the user claims multiple laptops?"*
  → **The Fraud Shield Risk Engine** tracks claim velocity, contradictory descriptions, and abnormal pattern graphs to flag bad actors before authorization.
